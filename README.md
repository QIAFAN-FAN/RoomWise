# RoomWise · 室内设计助手

一个**单文件**的对话式室内设计顾问网页 —— 打开即用，不用安装、没有第三方依赖、没有 CDN。

**在线使用：** <https://room-wise-psi.vercel.app>

> 每个版本改了什么 → **[更新日志 CHANGELOG.md](CHANGELOG.md)** ｜ **[版本发布](../../releases)**

---

## 🏆 最需要先解决的（必做清单）

这个工具最实用的部分：**钱和精力该先花在哪**。

- **9 个空间 × 3 个类别 = 115 条**必做清单，全部**内置**在网页里 ——
  **打开即看，不联网、不调用 AI、不花钱、不用等**
- 内容从《装修避坑手册（2025）》**提炼成一句话判断**（不是搬运原文）
- 每条按五个维度评分（返工代价 / 安全影响 / 替换难度 / 使用频率 / 感知强度），
  排成 **S / A / B / C** 四个梯队：
  **S** 做错要砸掉重来 · **A** 重点花钱 · **B** 够用就行 · **C** 可以后补
- **四种预设权重**：均衡（默认）/ 家有老人小孩 / 预算紧 / 追求品质 —— 切换只做本地重排
- 每条展开是**九件事**：
  **为什么先做 · 正确做法 · 做错了会怎样 · 怎么验收 · 参考花费 · 关键数字**，
  外加**展开说清楚**（百来字大白话详解）、**依据**（引到手册章节或国标）、
  **💡 经验提醒**（最容易踩的那个坑）
- 每条两个按钮：
  - **问设计师** —— 带着这一条进对话，自动把问题发出去
  - **联网搜索** —— 弹出独立窗口，去搜**别人家实际怎么做的**（论坛帖子、装修日记、
    知乎回答），返回摘要 + 可点来源链接；结果会按条缓存，点「重新搜」再换一批

> 覆盖的 9 个空间：厨房 / 卫生间 / 客厅 / 卧室 / 餐厅 / 书房 / 玄关 / 阳台 / **全屋**，
> 每个空间都分「硬装 · 隐藏 / 硬装 · 表面 / 软装」三张榜。

- 每条带一个**证据等级角标**：**国标强制** / **行业共识** / **看需求**
  （事实标签，不是评分）
- 「怎么验收」是一张**照着做的动作卡**：什么时候 / 拍什么 / 看什么 / 不合格 / 怎么办

## 🚪 第一次用？按这个顺序

首页是一张**三步走的引导卡**，跟着点就行：

**第一步：先看全屋**（钱怎么分、合同怎么签、工期怎么排）
→ **第二步：挑一个房间看细节**（厨房、卫生间、卧室 —— 每个房间各有各的坑）
→ **第三步：拿不准就问 AI**（把尺寸和情况说清楚，就有针对你家的答案）。

底栏的 **🚪 房间**点进去先到「**进哪个房间？**」，选一个房间后才进它的**主页** ——
主页上最上面才是「最先看这个（N 条）」的榜单入口，不会一上来就把榜单糊你脸上。

**没填 API Key 也能用**：全屋和房间的内置清单完全离线，不联网、不花钱；
Hero 只在首页出现，进到房间 / 工具 / 问 AI 之后就收起来，内容直接顶上来。

## 🧰 工具箱 · 装修防坑（AI 工作台）

**入口在顶栏的 🧰**（首页不再铺工具箱）。

工具箱里每个都支持**填自己的情况 + 传截图 + 联网核对**，生成针对你家的分析：

- **📋 报价单陷阱** —— 把报价单粘进来（或传截图），找出后面会加钱的地方
- **🗣 工头话术** —— 把工头原话丢进来，翻译成字面意思 / 大概率意思 / 风险，
  并给三种回法（缓和 / 直接 / 合同式）
- **❓ 该问什么** —— 按你的阶段和户型生成提问清单，每个问题带「为什么问 / 对方可能怎么答 / 怎么判断 / 怎么追问 / 写进合同哪一句」
- **💰 预算分配** —— 输入总预算和房屋情况，给出隐藏 / 表面 / 软装三块的分项方案与提醒
- **⚖️ 设计决策** —— 你家的尺寸、层高、人口、习惯，加上「该不该做」的结论、
  代价、什么情况别做、替代方案

生成结果可以**复制 / 导出 Markdown / 问设计师 / 保存到当前对话**；
生成中有停止按钮，失败可重试，同参数会读缓存。

> 没填 API Key、断网或接口失败时，会显示**内置通用参考**并明确标注
> 「这不是根据你的情况生成的」—— 也就是原来的静态清单，它们被保留下来做兜底。

## 💬 对话式咨询

- 像跟设计师聊天一样一直追问；会算尺寸、排工序、列验收要点
- **整理成表** —— 抽出尺寸表 / 施工顺序 / 验收清单
- **画个平面示意图** —— 按布局在前端画出来
- **可选联网检索** —— 回答附可核对的来源链接，正文里的 `[1] [2]` 可点跳转
- **可选产品推荐** —— 三档：自动（开了联网才推荐）/ 总是开启 / 关闭
- **计费单价可自己填** —— 设置里填输入/输出单价，官方改价后不用等新版本
- **灵活度 14 档 + 自定义** —— 0.0 严格 → 2.0 最大，工具箱还能临时覆盖
- **被截断会自动提示** —— 撞到长度上限时给一个「继续写完」按钮
- **可选展示思维链** —— 思考中显示最近几行，结束后收成一行横条
- **上传照片分析** —— 最多 4 张，自动压缩后再发
- 改问题重答 · 单条重新生成 · 停止后「继续说完」

## 📋 补充条件（填了答案更准，不填也能问）

面积尺寸 · 层高 · 房屋类型（毛坯 / 旧房改造 / 精装房）· 所在楼层 · 朝向 ·
常住人口 · 有没有老人 · 有没有小孩 · 有没有宠物 · 预算档位 ·
风格偏好 · 特殊需求（无障碍 / 隔音 / 智能家居 / 收纳）· 一句话补充

填了哪些就带进上下文，历史与云端一起存。

## ☁️ 账号与历史

- **邮箱密码注册 / 登录**（Supabase）；登录后历史存云端，换设备、换浏览器都能接着看
- **不登录也能正常用** —— 历史只留在这次页面里，关掉就没有
- 也可以换成**你自己的 Supabase**：设置 →「Supabase 服务器」填上自己的网址与可发布密钥，
  并先在自己的项目里跑一次 [`Supabase建表.sql`](Supabase建表.sql)

## 🚀 怎么用

1. 打开 <https://room-wise-psi.vercel.app>（或把 `index.html` 存到本地双击打开）
2. 右上角 **⚙** → 填自己的 **DeepSeek API Key**（在 <https://platform.deepseek.com> 申请）
   - Key 只保存在你自己的浏览器里，只发送给 `api.deepseek.com`
3. （可选）右上角 **👤** → 邮箱密码注册 / 登录，历史就能存到云端
4. 想直接看结论 → 进任意空间点「最需要先解决的」；想细问 → 直接在输入框里说

## 📱 界面与阅读

- 手机与电脑都自适应；**字号可调**（小 / 标准 / 大 / 特大）
- **页面配色**三档：自动（跟随系统）/ 白天 / 黑夜
- 回答长度 **6 档**：极简 150 / 简短 300 / 标准 600 / 详细 1000 / 很长 1500 / 最长 2000 字
- 发出问题后的视口位置可设：**停在新回答的开头**（默认）或**一直跟到最新**
- 密码框带「显示 / 隐藏」小眼睛

## 🔒 关于数据与隐私

- **DeepSeek API Key 不在这个仓库里** —— 它只存在每个使用者自己的浏览器中，只发往 `api.deepseek.com`
- 网页里内置的 Supabase **可发布密钥**（publishable / anon key）设计上就是公开的；
  数据安全由数据库的 **RLS（行级安全）** 保证 —— 每个账号只能读写属于自己的记录
- 必做清单的 115 条数据是**内置**的，不联网也不上传

## 版本

当前版本：**`v0.2.5`**（页面右上角也会显示）

### v0.2.5 有什么不一样

- **能返回了** —— 接上了浏览器历史（hash 路由）：手机侧滑返回、浏览器后退键都不会再
  直接退出应用；页面可以分享、收藏、新标签打开，**刷新还能回到当时那一页**
- **桌面有主导航了** —— >640px 时顶栏出现「首页 / 房间 / 工具箱 / 问 AI」，当前页高亮
- **每一页都知道自己在哪** —— 面包屑右侧有「第 N 步 / 共 3 步」，和首页三步引导卡同一套说法
- **第一次打开也看得懂** —— 首页给了三个一键示例（「3 万块钱先做厨房还是卫生间？」这类），
  点了直接开始聊；榜单的四个预设收进「排序方式」折叠并说明「只改排序、不重新请求」
- **不用一次填 13 格** —— 补充条件默认只展开 4 项，其余收进「填得更准」
- **名词有解释了** —— 空间页新增「装修名词速查」，打压试验 / 闭水试验 / 空鼓 / 找平 /
  增项 / 隐蔽工程 / 动线 / E0 级 等 12 个术语各一句人话
- **对话里也有风险提示了** —— 每条 AI 回答下方常驻「仅供参考，不构成施工依据」
- **「房间 / 问 AI」改成一行两个大字卡**，手机上接近半屏宽
- **术语统一** —— 全站不再叫「排行榜」，统一叫「**必做清单**」；
  「问设计师」→「问 AI」，「联网搜索」→「搜别人家怎么做的」
- **修了一批实测 bug** —— 包括「查看全部」点了没反应、从搜索点进清单 tab 总是不对、
  同一条记录每次进榜单都自己弹开、「先看必做清单（免费）」点了不动、返回时清空对话、
  顶栏标题显示成「厨房」等
