# RoomWise · 室内设计助手

一个单文件的对话式室内设计顾问网页。打开即用，不用安装任何东西、没有外部依赖。

> 每次更新改了什么，见 **[更新日志 CHANGELOG.md](CHANGELOG.md)**。

## 它能做什么

- 按空间提问（卫生间 / 厨房 / 客厅 / 卧室 …），像跟设计师聊天一样一直追问下去
- 会算尺寸、排工序、列验收要点，还能「整理成表」「画个平面示意图」
- 支持上传照片分析；可选联网检索，并附可核对的来源链接
- 可选展示思维链；支持改问题重答、重新生成、继续说完
- 登录后对话历史保存到云端，换设备也能接着看

## 怎么用

1. 打开网页（线上直接访问；本地则双击 `index.html`）
2. 右上角 **⚙** → 填自己的 **DeepSeek API Key**（在 <https://platform.deepseek.com> 申请）
   - Key 只保存在你自己的浏览器里，只发送给 `api.deepseek.com`，不会上传到任何地方
3. 右上角 **👤** → 用邮箱密码注册 / 登录
   - 不登录也能正常聊天，只是历史只留在这次页面里，关掉就没了
4. 选一个空间，或者直接输入你的问题

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 整个应用。单文件，无第三方脚本、无 CDN 依赖 |
| `Supabase建表.sql` | 想把自己的历史存进**自己的** Supabase 时用；内含建表语句与 RLS 策略 |

## 关于数据

- 网页里内置了一个 Supabase **可发布密钥**（publishable / anon key）—— 这类密钥本来就是设计成公开的，
  数据安全由数据库的 **RLS（行级安全）** 策略保证：每个账号只能读写属于自己的记录。
- 想换成你自己的 Supabase：在 **设置 → Supabase 服务器** 里填自己的网址与密钥，
  并先在自己的项目里跑一次 `Supabase建表.sql`。
- **DeepSeek API Key 不在这个仓库里**，它只存在每个使用者自己的浏览器中。
