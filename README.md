# RoomWise · 室内设计助手

一个**单文件**的对话式室内设计顾问网页 —— 打开即用，不用安装、没有第三方依赖、没有 CDN。

**在线使用：** <https://room-wise-psi.vercel.app>

## 🏆 最需要先解决的排行榜

这个工具最实用的部分：**钱和精力该先花在哪**。

- **8 个空间 × 3 个类别 = 102 条**判断，全部**内置**在网页里 ——
  **打开即看，不联网、不调用 AI、不花钱、不用等**
- 内容从《装修避坑手册（2025）》**提炼成一句话判断**（不是搬运原文）
- 每条按五个维度评分（返工代价 / 安全影响 / 替换难度 / 使用频率 / 感知强度），
  排成 **S / A / B / C** 四个梯队：
  **S** 做错要砸掉重来 · **A** 重点花钱 · **B** 够用就行 · **C** 可以后补
- **四种预设权重**：均衡（默认）/ 家有老人小孩 / 预算紧 / 追求品质 —— 切换只做本地重排
- 每条展开是**九件事**：
  **为什么先做 · 正确做法 · 做错了会怎样 · 怎么验收 · 参考花费 · 关键数字**，
  外加**展开说清楚**（百来字大白话详解）、**依据**（引到手册章节或国标）、
  **💡 经验提醒**（最容易踩的那个坑）
- 每条两个按钮：
  - **问设计师** —— 带着这一条进对话，自动把问题发出去
  - **联网搜索** —— 弹出独立窗口，去搜**别人家实际怎么做的**（论坛帖子、装修日记、
    知乎回答），返回摘要 + 可点来源链接；结果会按条缓存，点「重新搜」再换一批

> 覆盖的 8 个空间：厨房 / 卫生间 / 客厅 / 卧室 / 餐厅 / 书房 / 玄关 / 阳台，
> 每个空间都分「硬装 · 隐藏 / 硬装 · 表面 / 软装」三张榜。

## 💬 对话式咨询

- 像跟设计师聊天一样一直追问；会算尺寸、排工序、列验收要点
- **整理成表** —— 抽出尺寸表 / 施工顺序 / 验收清单
- **画个平面示意图** —— 按布局在前端画出来
- **可选联网检索** —— 回答附可核对的来源链接，正文里的 `[1] [2]` 可点跳转
- **可选产品推荐** —— 三档：自动（开了联网才推荐）/ 总是开启 / 关闭
- **被截断会自动提示** —— 撞到长度上限时给一个「继续写完」按钮
- **可选展示思维链** —— 思考中显示最近几行，结束后收成一行横条
- **上传照片分析** —— 最多 4 张，自动压缩后再发
- 改问题重答 · 单条重新生成 · 停止后「继续说完」

## 📋 补充条件（填了答案更准，不填也能问）

面积尺寸 · 层高 · 房屋类型（毛坯 / 旧房改造 / 精装房）· 所在楼层 · 朝向 ·
常住人口 · 有没有老人 · 有没有小孩 · 有没有宠物 · 预算档位 ·
风格偏好 · 特殊需求（无障碍 / 隔音 / 智能家居 / 收纳）· 一句话补充

填了哪些就带进上下文，历史与云端一起存。

## ☁️ 账号与历史

- **邮箱密码注册 / 登录**（Supabase）；登录后历史存云端，换设备、换浏览器都能接着看
- **不登录也能正常用** —— 历史只留在这次页面里，关掉就没有
- 也可以换成**你自己的 Supabase**：设置 →「Supabase 服务器」填上自己的网址与可发布密钥，
  并先在自己的项目里跑一次 [`Supabase建表.sql`](Supabase建表.sql)

## 🚀 怎么用

1. 打开 <https://room-wise-psi.vercel.app>（或把 `index.html` 存到本地双击打开）
2. 右上角 **⚙** → 填自己的 **DeepSeek API Key**（在 <https://platform.deepseek.com> 申请）
   - Key 只保存在你自己的浏览器里，只发送给 `api.deepseek.com`
3. （可选）右上角 **👤** → 邮箱密码注册 / 登录，历史就能存到云端
4. 想直接看结论 → 进任意空间点「最需要先解决的」；想细问 → 直接在输入框里说

## ⌨️ 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl` / `Cmd` + `K` | 打开设置 |
| `Ctrl` / `Cmd` + `/` | 快捷键速查 |
| `Esc` | 逐层返回 |
| `↑` / `↓` | 输入框为空时，跳上 / 下一条提问 |

## 📱 界面与阅读

- 手机与电脑都自适应；**字号可调**（小 / 标准 / 大 / 特大）
- **页面配色**三档：自动（跟随系统）/ 白天 / 黑夜
- 回答长度 **6 档**：极简 150 / 简短 300 / 标准 600 / 详细 1000 / 很长 1500 / 最长 2000 字
- 发出问题后的视口位置可设：**停在新回答的开头**（默认）或**一直跟到最新**
- 密码框带「显示 / 隐藏」小眼睛

## 📁 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 整个应用。单文件，无第三方脚本、无 CDN 依赖 |
| `Supabase建表.sql` | 想把自己的历史存进**自己的** Supabase 时用；含建表语句与 RLS 策略 |

## 🔒 关于数据与隐私

- **DeepSeek API Key 不在这个仓库里** —— 它只存在每个使用者自己的浏览器中，只发往 `api.deepseek.com`
- 网页里内置的 Supabase **可发布密钥**（publishable / anon key）设计上就是公开的；
  数据安全由数据库的 **RLS（行级安全）** 保证 —— 每个账号只能读写属于自己的记录
- 排行榜的 102 条数据是**内置**的，不联网也不上传
