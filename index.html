设置

连接（填 API Key）
Key 只保存在本机浏览器 localStorage；发起对话时随请求发送给 DeepSeek 官方接口（api.deepseek.com），除此之外不会发送给任何第三方。 公用电脑用完请点「清除 Key」。
Supabase 服务器（高级，可选）
这里跟登录无关 —— 登录 / 注册在右上角的 👤。这一组只管：记录存到哪台服务器。
默认用内置的那台，正常使用不用碰这里：别人用邮箱密码注册，账号和对话记录就都进内置项目。
想让记录进你自己的 Supabase：先把上面两项填好并保存，然后重新注册 / 登录一次 —— 账号也是建在你的项目里的。原有的账号与历史不会自动搬过来（它们还留在原来的项目里）。
填之前记得先在自己的项目里跑一次建表 SQL（见下方）。
可发布密钥本来就是设计成公开的，放进网页里不危险；但 RLS 必须开，否则谁都能读整张表。
模型与回答（技术项）
deepseek-flash 原生支持多模态与混合思考：同一个模型名靠 thinking 参数切换。
思考模式下 temperature 不生效，本工具会自动省掉，并按强度给思维链留额度。
计费：空闲时段 输入 1 元 / 输出 4 元（每百万 tokens）；工作日 9:00-12:00、14:00-18:00 为高峰，价格翻倍。
只影响费用估算，不影响实际扣费；留空就用内置价格表（缓存命中价按输入价 2% 估）。
只在「深度思考」档位生效。
0.0 最严格、2.0 最发散；思考模式下 temperature 不生效（会自动省掉）。
联网与图片
图片按 Flash 费率计，单张最多折算 384 tokens，实际花销极低。
自动：按这一条有没有开「🌐 联网」来定 ——
开了联网就推荐（可以附上可核对的来源链接），没开就不推荐；
也可以强制「总是开启」或「关闭」。
未联网：只给类别、规格和价格区间，不给品牌型号。已联网：可以给具体品牌 / 型号，但必须附本次搜到的真实来源链接。
界面与偏好
手机和电脑都生效：只放大文字，不改变留白与布局。
选「白天 / 黑夜」会覆盖系统设置，手机和电脑都生效。
「停在新回答的开头」：回答边写边长，页面不跟着往下跑 —— 自己往下滚一下就恢复跟随。
